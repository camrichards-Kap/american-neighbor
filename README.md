# American Neighbor prototype

An interactive, single-file prototype of American Neighbor, a local services marketplace for Goldsboro, North Carolina, connecting neighbors with service members, veterans and military family.

Everything in it is fictional demo data: the people, reviews, prices and verification statuses. No real payments, identity checks or background checks happen here.

American Neighbor is a private business. It is not affiliated with, endorsed by, or sponsored by the Department of Defense or any government agency.

Open `index.html` in a browser, or view the published page through GitHub Pages.
